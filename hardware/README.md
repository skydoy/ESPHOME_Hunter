# Hardware photos

Photos of the Hunter_LS PCB and of an installation in a Hunter X-Core, by **Luís Soares**
([luisfosoares/Hunter_LS](https://github.com/luisfosoares/Hunter_LS)). Full-size originals.
The installation photos are of a v1.0.0 board; v1.1.x and v2.0.0 fit the same way (follow the
labels printed on the board).
