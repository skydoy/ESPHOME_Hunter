# ESPHome Hunter

**Your Hunter X-Core irrigation controller in Home Assistant.** Plug in by USB, click Install, done. No YAML, no cloud.

<div class="hero-install" markdown="1">
[⚡ Open the web installer](https://skydoy.github.io/ESPHOME_Hunter/){ .md-button .md-button--primary }
</div>

Works only with **Luís Soares's Hunter_LS** boards (v1.x or v2.0.0) in a Hunter controller with REM, SEN and zone terminals (for example the X-Core).
