# ESPHome Hunter

**O teu programador de rega Hunter X-Core no Home Assistant.** Liga por USB, carrega em Instalar, feito. Sem YAML, sem nuvem.

<div class="hero-install" markdown="1">
[⚡ Abrir o instalador web](https://skydoy.github.io/ESPHOME_Hunter/){ .md-button .md-button--primary }
</div>

Só funciona com as placas **Hunter_LS do Luís Soares** (v1.x ou v2.0.0) num programador Hunter com terminais REM, SEN e das zonas (por exemplo o X-Core).
